# Радар заказов kwork и вакансий hh.ru с оценкой ИИ и ботом в MAX

Находит новые заказы на kwork и вакансии на hh.ru, отсеивает неподходящие по правилам и стоп-словам, остальные оценивает Claude по письменным критериям и присылает карточки в бот MAX. По кнопке в карточке заказа Claude пишет черновик отклика. Работает ежедневно на Windows: Планировщик заданий и команды бота.

## Что умеет

- hh.ru: поиск по фильтрам (удаленно, частичная занятость, проектная работа), отсев чужих профессиональных рубрик и стоп-слов в названии, склейка дублей «работодатель + название».
- kwork: сбор заказов из выбранных рубрик, отсев по цене и списку сервисов, чтение вложений (docx, xlsx, pdf, архивы).
- Оценка: Claude (`claude -p`) по файлу критериев — 🟢 подходит, 🟡 уточнить, 🔵 можно предложить автоматизацию, 🔴 мимо; в карточке — причина и подходящее резюме или первая фраза отклика.
- Память: оцененные вакансии и заказы не оцениваются повторно; ошибки оценки видны в отчете, а не как «новых нет».
- Бот MAX: команды `/hh` и `/kwork`, кнопки «черновик» и «другой вариант» с комментарием; предупреждение, если вход на площадку устарел.
- Вход на площадки — cookie, обновляется сам из ответов сайта.

## Как устроено

```
Планировщик / команда в MAX ─► run.ps1 ─► radar.js ─► поиск и отсев ─► claude -p (критерии) ─► карточки в MAX
Кнопка «черновик» ─► draft.js ─► claude -p (шаблон отклика) ─► черновик в MAX
listen.js — один опросчик бота MAX: команды и кнопки владельца
```

- `hh-radar/` — радар вакансий; `kwork-radar/` — радар заказов и черновик отклика, шаблон `reply-template.md`; `bot/` — слушатель бота MAX и меню команд.
- `criteria/` — примеры критериев отбора и профиля исполнителя; свои (`hh.md`, `kwork.md`, `profile.md`) пишутся по ним и в репозиторий не попадают.

## Стек

Node.js без зависимостей, PowerShell, Claude Code CLI, MAX Bot API, Планировщик заданий Windows.

## Запуск

1. Скопировать `.env.example` в `.env`: cookie hh и kwork, токен бота MAX, путь к сертификату Минцифры.
2. Написать критерии по `criteria/*.example.md`, настроить фильтры в `config.json`.
3. Написать боту /start и запустить `pwsh kwork-radar/run.ps1` — радар запомнит владельца (`state/owner.json`).
4. `pwsh hh-radar/run.ps1 -Period 1` — пробный прогон hh за сутки; `pwsh bot/run-listener.ps1` — бот с командами и кнопками.
